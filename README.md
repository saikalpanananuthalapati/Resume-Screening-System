# Resume Screening System

An NLP-based Resume Screening System that automatically ranks and filters resumes using TF-IDF Vectorization and Cosine Similarity. The system matches candidate resumes with job descriptions and provides relevance scores to assist recruiters in the hiring process.

## Features
- Resume Parsing
- TF-IDF Vectorization
- Cosine Similarity Matching
- Resume Ranking
- Job Description Analysis
- Automated Candidate Screening

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- NLP
- TF-IDF
- Cosine Similarity

## Usage
1. Upload resumes and a job description.
2. The system analyzes and compares resumes.
3. Candidates are ranked based on similarity scores.
4. Recruiters can identify the best matching candidates quickly.
